The question

How much can a personal site do while asking for as little as possible?

The approach
  1. Give the portfolio, profile and journal their own pages, with a consistent visual identity and direct navigation.
  2. Generate static pages at build time. Keep fonts and assets local, and use public profile links instead of collecting messages.
  3. Keep private source documents out of the project. Review visible content, metadata and generated files before any publication.
The result

A working portfolio and journal, published with permission for review. Journal entries remain labelled as editorial drafts.

Context & boundaries

This is the site you are viewing, not a client engagement. No employer, customer or private career details are disclosed. The tree is a generated visual, not a photograph of a real person, location or engagement.
